# Clover History

This directory preserves superseded specifications, old architecture documents and research milestones.

Historical material is evidence of how Clover evolved. It is **not** automatically current SSOT.

When older Clover V4/V5/V6 documents are imported, they should be placed under this directory (for example `docs/history/specs/`) and should retain their original wording and dates.

Current authority order:

1. `README.md` / `docs/research-question.md`
2. `PRINCIPLES.md`
3. `STATUS.md`
4. `ROADMAP.md`
5. current architecture documents
6. active hypotheses
7. research notes
8. historical documents

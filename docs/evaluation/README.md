# Evaluation Map

Clover treats evaluation as a set of instruments for different capabilities, not a single leaderboard target.

Current categories:

- intuitive physics;
- shortcut-resistant physical understanding;
- causal/counterfactual reasoning;
- temporal/video understanding;
- egocentric real-world video;
- lifelong robot learning;
- long-horizon manipulation;
- real embodied generalization.

See [Benchmark Map](benchmark-map.md) and [Evaluation Principles](evaluation-principles.md).

No benchmark reproduction campaign is currently in progress; the present phase is research mapping and public foundation building.

## 一、前沿论文 / 方法（15）

1. **VLA-Δ：监督"状态变化量"而非"演示动作"，真机击败 π₀.₅（arXiv，10-15）**
浙大 ZJU-OmniAI 团队诊断当前 VLA 直接拟合"观测→演示动作"映射、容易过拟合观测-动作对应关系；VLA-Δ 把"当前帧到未来帧的物理变化量"作为显式学习目标，配合标注了任务语义与视觉运动变化的大规模预训练数据。在 LIBERO、RoboTwin 上达到 SOTA 竞争水平，真机实验胜过 π₀.₅，且推理时无任何额外开销。与 Sber 的 GreenWAM 同属近期声称击败 π₀.₅ 的新模型。[来源](https://aiweekly.co/alerts/vla-trains-robot-policies-on-state-deltas-beats)

2. **KAIST SQAM：闭式标量伴随量替代逐步 Jacobian，OGBench 最难四域 +18~35 点（10-08，HuggingFace 每日论文）**
用闭式标量伴随（scalar adjoint）替代 flow-policy RL 里昂贵的逐步 Jacobian 计算，在 OGBench 上把最难的四个域（antmaze-giant、humanoidmaze-large、cube-triple、cube-quadruple）相对最强基线提升 18~35 个百分点。随后迁移到真机：Rainbow RB-Y1 双臂 + 两只 20 自由度灵巧手 + RLDX-1 VLA，翻塑料袋 25/30、吸管插杯 15/30，远超 SFT 基线。代码已开源。这是 KAIST 本月被追踪到的第二篇机器人研究。[来源](https://aiweekly.co/alerts/kaist-sqam-beats-ogbenchs-hardest-tasks-by-18-35-points)

3. **World-Env：把世界模型当 VLA 后训练的"虚拟环境"（arXiv 2509.24948，持续更新至 2026）**
不再用真机交互做 VLA 后训练，而是用世界模型生成虚拟环境：解决传统 VLA 依赖真机带来的数据低效、安全约束与执行低效。在复杂机器人操作任务上验证可行，被视为资源受限场景下的可扩展后训练方案——"世界模型即数据工厂"路线的典型实现。[来源](https://arxiv.org/abs/2509.24948v1)

4. **JoyAI-RA 0.1：多源异构预训练的 VLA 具身基础模型（arXiv 2604.20100）**
把多模态网页数据、第一人称人类操作视频、仿真生成轨迹、真机演示四种来源统一进一个预训练配方，设计多层级预训练策略与显式动作空间统一来缓解 embodiment gap。在仿真与真机 benchmark 上都超过 SOTA，论证了"异构多源预训练"对开放世界泛化的价值。[来源](https://arxiv.org/pdf/2604.20100)

5. **Reflection Beam 501B：Apache 2.0 全权重开源（10-17/18）**

## 三、对我工作的启示

1. **把监督目标从"动作"搬到"状态变化量"：VLA-Δ 的思路与 Clover 的认识论定位天然对齐。** VLA-Δ 证明了显式监督"当前帧→未来帧的物理变化"比拟合观测-动作对应更有效、且真机可赢 π₀.₅。Clover 的输出本就是"带许可证的可查询世界状态"而非动作指令——建议在 V5 的世界状态 readout（UncertaintyLens 附近）加一组 delta-监督对照实验：同样的观测流，一路监督动作、一路监督状态变化，看哪边的不确定性标定更诚实。
2. **世界模型正在成为 VLA 后训练的"虚拟环境"：Terrarium 数据引擎的对标清单更新。** World-Env、Odyssey-3（自回归扩散世界模型）、NVIDIA Physical AI Data Factory Blueprint（Cosmos 生成/倍增/评分/筛选合成数据）是同一条"算力换数据"路线；AWS 刚把 Isaac Sim/Lab+GR00T+OSMO 做成开源 Terraform 参考栈。Terrarium 的"数据引擎（fast rollout + 保功能几何增强）"可以对照这条清单做一次 gap 分析，尤其补上"难例/长尾场景的生成式覆盖"一环。
3. **人类演示不是唯一解：自博弈与纯合成数据两条路线都在加注。** Skild 用"进球"单目标 + 自博弈在 Isaac Sim 里跑出 140 年、涌现运球/铲球/倒地恢复后 sim-to-real 上人形；DexForce 则公开押注"10 万亿样本靠真机采集不可能"，All-in 虚拟数据。启发：Terrarium 的 Gym/Exam 双模式之外，值得立项第三条数据引擎——"单目标 + 自博弈课程"，把任务目标本身变成课程生成器。
4. **KAIST SQAM 的工程美学值得学：闭式解替代暴力计算。** 用闭式标量伴随量替代 flow-policy RL 的逐步 Jacobian，OGBench 最难四域 +18~35 点——"紧凑、闭环、高效"正是 Jack 的工程美学。Terrarium RL 训练栈里可以实验同类"解析化"加速：先把训练瓶颈 profile 出来，再看有没有闭式/解析替代，而不是一味堆并行环境数。
5. **基础模型正在"服务化"：PI 的 Pi API + ROS 3 原生 VLA API 是产品形态信号。** PI 把"上传数据→托管微调→推理网关"做成 waitlist 服务，ROS 3 把 VLA 写进中间件标准——"模型即服务/即基础设施"是 2026 下半年的产品共识。Clover 的 SEP 已是进程内 ABI 且离线优先（铁律），短期不动；但值得在前沿追踪里单列"查询接口服务化"一条线，观察云端托管微调 + 推理网关的商业验证进度。同时把 π₀.₅ 设为公开对标锚点：VLA-Δ、GreenWAM、LingBot-VLA 本周都在围着它打，Clover 将来的外部对标也应包含这一基线。

## 一、前沿论文 / 方法（15）

1. **COAP：推理时干脆不用 VLA（10-14，NUS NExT++）**
COAP 提出 *Code-Only-as-Policy*：只要能从相机+本体感知估计出完整结构化状态，下游逻辑就全部写成显式代码，决策环里零模型调用。在 RoboDojo 的 42 个双臂操作任务上达到 70.24% 成功率，且测试时决策阶段没有一次模型调用。作者把共享代码库看作 LLM 递归自改进的天然基质。[来源](https://extrapolator.ai/2026/10/14/coap-removes-vla-from-robot-inference-hits-70-on-robodojo-bimanual/)

2. **ACCRUE：真机 RL 训练成本砍掉三到七成（10-13，NVIDIA + KAIST）**
 continual off-policy RL 框架：轻量 actor/critic 跨任务继承，新技能复用此前 RL 阶段的行为与价值知识；老行为靠对少量保留 episode 蒸馏目标保留，近零遗忘。在接触丰富的装配序列（仿真+真机）上，真机训练时间缩短 31.0%–68.5%。与 TacitVLA、GreenWAM 同周上线，continual-RL 成了本周论文侧最拥挤的赛道。[来源](https://aiweekly.co/alerts/nvidia-kaists-accrue-cuts-real-robot-rl-training-31-685)

3. **TacDyn-WAM：触觉预测"接触变化"而非"触觉像素"（arXiv 09-30，注日期）**
异构视觉-触觉世界动作模型：主张对触觉传感器未来帧做逐像素重建是浪费，真正该预测的是接触如何演化（变稳、对不准、变危险）。这是一条设计原则而非定论——作者自己承认还需要在不同触觉硬件、更多样物理环境、大样本与独立复现上经受考验。[来源](https://marychuks.com/robots-predict-contact-change-tactile-world-model/)

4. **Priming Models：一步生成还用"预热"吗？（arXiv 2610.20331，10 月）**
两阶段一步生成框架：先训练生成器从损坏输入重建干净数据（reconstruction priming），再在特征空间做生成/真实分布匹配（最优传输 + Sinkhorn）。在 ImageNet、文生图和动作条件世界建模上都改善了训练算力–质量权衡；核心洞见是重建预训练让分布优化不再脆弱。这对世界模型的采样效率有直接参考价值。[来源](http://arxiv.org/abs/2610.20331v1)

5. **GlanceWAM：想象力放慢时钟，动作保持高速（arXiv 2608.23927，9 月，注日期）**
解决"逐步想象太慢、不想象太盲"的双速设计：一个共享视频模型在后台生成约 3 秒后的单帧潜空间前瞻（glance），动作头以每 chunk 48ms 解码动作。消融证明前瞻是承重件；真机对比胜过 π0.5。这是本周 VLA 效率浪潮（Fast-VLA、VLA-Δ）之外另一条异构路线：慢想象 + 快执行。[来源](https://arxiv.org/abs/2608.23927)

6. **GSP-3D：3D 高斯溅射 + 世界模型做双臂操作（10-17 报道）**
用 3D Gaussian Splatting 表征场景，学出"物体连续运动、遮挡平滑演化"的经验转移先验，并惩罚偏离该先验的高斯参数突变。在 RoboTwin 2.0 双臂 benchmark 上，50 个专家演示/任务的同等条件下全面胜过 RDT、π0、ACT、DP、DP3（后者最强基线）。消融证实 3DGS 表征与世界模型辅助损失缺一不可。[来源](https://bioengineer.org/robots-learn-to-see-the-future-with-gaussian-splatting-for-two-armed-tasks/)

7. **RoboDojo：30 个"机器人大脑"同场考试（arXiv 2607.04434，7 月；10-17 专题解读）**
统一的仿真+真机评测基准：故意打乱房间布局、藏起线索、压缩容错余量、考没练过的技能。结论是演示与可靠通用操作之间仍有巨大鸿沟——randomized 条件下不少模型的成绩跌到个位数；难点地图指向记忆、精度和分布外应对。这正是 benchmark 该做的事：让差距可测量、可追踪。[来源](https://medium.com/@banerjeevictor06/thirty-robot-brains-took-the-same-test-968bf6532976)

8. **Artisan：多智能体 + 仿真反馈生成可用关节 3D 资产（10-12，NTU/ETH/Microsoft/Oxford/Cambridge）**

## 一、前沿论文 / 方法（15）

1. **OneWM：视频预测与动作学习互相成就（新 arXiv）**
OneWM 把"动作既是世界预测的条件、又是策略学习的目标"放进同一个混合 Transformer 里做统一因果训练，视频主干用 Wan2.2-TI2V-5B 初始化。在移动操作 benchmark RoboCasa365 上拿到 36.68%，而 NVIDIA GR00T N1.6 是 21.90%、π0 是 14.80%；在 LIBERO-Plus 上也达到 59.27%，超过 Fast-WAM（49.70%）和自身消融。最安静的结论是反方向：加了动作生成损失后，同一骨干的视频预测指标（PSNR/SSIM/FVD）也全线变好。[来源](https://aiweekly.co/alerts/onewm-couples-world-model-and-policy-tops-robocasa365-at-3668)

2. **VLA-Δ：不学动作，学"物理变化量"（10-15，浙大 ZJU-OmniAI）**
现有 VLA 把观测直接映射到示教动作，容易过拟合"观测–动作对应"。VLA-Δ 把监督目标换成当前帧到未来帧之间的物理状态变化（delta），并为此构建了标注"任务相关语义 + 视觉运动变化"的大规模预训练数据。在 LIBERO、RoboTwin 上与 SOTA 相当，真机实验中超过 Physical Intelligence 的 π0.5；部署时推理开销与标准 VLA 完全相同——delta 只在训练侧存在。这是继 Sber GreenWAM 之后本周第二个宣称真机胜过 π0.5 的工作。[来源](https://aiweekly.co/alerts/vla-trains-robot-policies-on-state-deltas-beats)

3. **Fast-VLA：一个 episode 只"想"一次（arXiv 2610.21389，10-15）**
VLA 把数十亿参数模型塞进控制闭环、每个动作块都重新算一遍任务上下文，但任务理解的变化远比机器人状态慢。Fast-VLA 每 episode 只调用一次冻结的 4B VLM，把指令+初始视角固化成多层 KV 任务记忆；在线轻量 actor 只用时间/手臂索引查询融合视觉与本体感受，检索任务上下文、预测动作块，无需重跑大模型。RoboTwin 2.0 上 92.46%/92.40%、LIBERO 95.95%；同硬件上均摊推理时间降 10.9–17.1 倍，在线常驻显存仅 1.22 GiB。"想一次、动全程"就是双相预算架构在 VLA 上的实例化。[来源](https://arxiv.org/abs/2610.21389)

4. **GreenWAM：一个世界模型同时做"预测"和"控制"，跨 20 种本体（10-13，Sber）**
机器人需要"预测动作如何改变场景"的世界模型和"选择动作"的策略，GreenWAM 让一个模型兼任两者：核心是共享解剖动作空间——20 个机器人家族（双臂、灵巧人形等）的关节全部映射到 79 个共享解剖槽位，再以 Cosmos 3 Edge 为基座做三模式联合训练。WorldArena 1.0 上轨迹/深度/3D 精度第一档；策略侧 RoboTwin 2.0 榜单前列、LIBERO-plus 零样本最高；真机人形上胜过从 π0.5 和 Cosmos 3 Edge 迁移的策略，并蒸馏为单步实时策略。四套 benchmark 权重与评测代码已开源（HF）。[来源](https://huggingface.co/papers/2610.18774)

5. **VLRLA：部署期 in-context 强化学习适应（arXiv 2610.19517，10-14）**
预训练 VLA 部署后"冻结在部署那一刻"，遇到新场景只能等下一次训练。VLRLA 给现有 VLA 外挂一个 RL 模块，从历史观测、动作、奖励、终止信号里学习；部署中策略逐步修正动作生成、参数完全冻结。在仿真和真机上都验证了向未见场景的渐进适应。观点：这是"部署即学习"的最小侵入方案——不碰权重，只在上下文里吃经验；与 PhysEvo 的"零权重更新"思路同属一个新兴范式。[来源](https://arxiv.org/abs/2610.19517)

6. **REKI：2.4B 开放 VLA，打出"性能–体积"新帕累托（arXiv 2610.22178，10-15）**
2.4B 的 VLA（VLM + flow-matching 动作专家），只在公开数据上预训练，在 LIBERO-Plus、RoboTwin Clean2Rand、RoboCasa365 上只输给约两倍体量的模型。关键设计是一个几乎零成本的记忆：动作专家里的几个 register token 逐帧汇总 VLM 输出并缓存在专家 cache 里，给策略带上"最近的过去"。消融显示记忆在仿真和真机都提成功率，并把姿态间震荡减少约 4 倍。数据、训练、推理、评测、部署全链路代码与所有权重全部开源。[来源](https://arxiv.org/abs/2610.22178)

7. **SimForcing：把仿真的运动先验蒸馏进真实域世界模型（arXiv 2610.06598，10-05）**
真机视频稀缺、仿真视频无限，但域鸿沟让仿真数据难用。SimForcing 把仿真里的运动先验蒸馏进真实域机器人世界模型，让世界模型先"在仿真里学会怎么动"，再迁移到真实分布；更进一步，用训好的世界模型初始化 VLA，LIBERO 成功率提升。对 Terrarium 这条线的直接意义：仿真不只是评估沙盒，更是世界模型预训练的燃料来源——"真值只用于验证"的合同可以放宽到"仿真真值用于蒸馏"。[来源](https://arxiv.org/abs/2610.06598v1)

8. **Long-WAM：给世界–动作模型加长上下文，且保持实时（arXiv 2610.10528，10 月）**
自回归机器人视频预训练 + 因果世界–动作适配，让模型吃更长的视觉历史；流式观测编码、异步执行、硬件特异加速保证实时控制。关键发现：更长上下文确实提成功率，但前提是视频基座本身是自回归预训练的（并行式预训练的增益小）。流式/异步/量化的边缘部署方案也一并给出，长时程任务上与分层规划结合效果好。这是 VLA"记忆问题"在 WAM 路线上的工程化解。[来源](http://arxiv.org/abs/2610.10528v1)

9. **PhysEvo：冻结的 Astra + 双智能体循环，真机 84% 成功率、零权重更新（10-06）**
用一个任务智能体执行、一个元智能体读轨迹、诊断失败、修正工具与技能、验证后重新部署，把冻结的 Astra VLM 包在环境试验的循环里。RoboDojo 仿真 42 任务 62.00%（基线 47.17%），最难的 8 个任务从 1.25% 干到 55.00%；AgileX PiPER 真机 5 任务 25 次试验 84.00%。核心命题：物理递归自我改进不一定要调权重，"元智能体吸收失败信号"本身就是学习。局限是真机评估规模小，泛化边界待定。[来源](https://aiweekly.co/editors-blog/found-first-physevo-84-real-world-robot-success-with-a-frozen-astra-no-weight)

10. **ForeAct3D：VLA 内部的策略接地未来世界建模（arXiv 2610.04607，10-06）**
VLA 预测未来观测时，预测和它将要执行的动作是脱钩的、且场景演化没有物理约束。ForeAct3D 用可学习的几何查询从策略表征解码深度、语义分割、相机位姿，得到当前与未来语义 3D 状态；未来查询以策略生成的动作块为条件，物理一致性闭包用"背景静态 + 实例刚性"约束两者。训练塑造共享表征，推理时不做未来预测、零额外开销。无机器人预训练做到 LIBERO 平均 98.3%、CALVIN 平均任务长度 3.73；真机空间放置/插入/序列操作从 6.7% 提到 37.8%。[来源](https://arxiv.org/abs/2610.04607)

11. **SWAP：按步为 VLA 路由策略（arXiv 2610.06926，10-07）**
单个 VLA 在不同任务阶段/环境下表现不一，SWAP 把策略选择做成离线 RL 问题：训练一个路由 critic，每一步根据当前观测选最合适的策略在线执行，不再整 episode 锁定一个策略。真机 DROID 任务成功率绝对提升最高 33%，成功轨迹的动作步数还缩短 28.3%。观点：这和 GreenWAM 的"一个模型多本体"是同一问题的两种答案——能力组合可以在训练侧做（统一模型），也可以在执行侧做（路由）。[来源](https://arxiv.org/abs/2610.06926)

12. **InterEvolve：用奖励程序搜索解锁接触丰富的人形任务（arXiv 2610.02196，10-01）**
接触丰富的人形任务（踢、推、搬）难在奖励函数难写、控制器不用重训。InterEvolve 让系统搜索"奖励程序"：3866 个电机模型训练片段、8 个仿真任务族，每轮 192 调参 + 192 确认 rollout，仿真宏平均成功率 86.5%，每轮仅 2.1 GPU 小时 + 23 万 token。观点：奖励设计本身可以被搜索自动化，这是 RL 在人形全身控制上规模化的务实路线；但物理侧只有定性演示，缺广义的真机成功率表。[来源](https://github.com/156631890/roboskin.ai/blob/HEAD/docs/seo/news-2026-10-04.md)

13. **Memento 3：模型权重不动，解出全部 25 个 ARC-AGI-3 游戏（10-08，华为诺亚方舟）**
华为诺亚方舟实验室 + UCL + 利物浦大学的团队报告：智能体在不更新语言模型权重的情况下解出全部 25 个公开 ARC-AGI-3 游戏，RHAE（相对人类动作效率）100.0，用了人类 44% 的动作数。学习发生在哪里？模型外的一本"可修订规则手册"：把规则转成可执行代码，用游戏实际行为校验。VISTA（10-05 报过）说"模型不笨，是眼瞎+失忆"；Memento 3 更进一步——给固定模型配上"会写代码、会自我纠错的外部记忆"，交互式推理的瓶颈可能在 harness 不在权重。[来源](https://dailyinference.news/articles/2026-10-12-25-of-25-reasoning-games-solved-and-the-model-never-changed-team/)

14. **人类大脑发育或成 AGI 的架构蓝图（10-16，Frontiers in Robotics and AI）**

## 三、对我工作的启示

1. **把"delta"做成 Clover 的一等学习/评测信号（复现 VLA-Δ 的核心洞见）。** VLA-Δ 证明：监督"状态变化量"比监督"动作"更抗过拟合。这与 Clover"认识论断言"的定位天然契合——断言的"差分"（世界状态如何变）本身就是可查询、可验证的对象。建议在 Terrarium 的 Exam 模式里加一个 delta-prediction 评测项：给定动作，预测世界状态的变化量；先用现有数据跑通，再决定是否进训练目标。

2. **Fast-VLA 是 PhaseGate 双相架构的公开对照组。** "冻结大模型想一次（任务记忆）+ 轻量 actor 在线查"正是 PhaseGate"感知/闭包双相预算"的异构实现，且它给出了硬数字（10.9–17.1× 推理加速、1.22 GiB 常驻）。建议把 Fast-VLA 列为 PhaseGate 的对标基线：它的 KV 任务记忆 ≈ 我们的闭包侧快照，对比两者在"任务切换时记忆是否失效"上的行为差异，能直接检验 PhaseGate 的设计假设。

3. **GreenWAM 的"共享解剖动作空间"值得 Terrarium 接口层借鉴。** 20 种本体映射到 79 个共享解剖槽位，让一个模型跨本体训练——Terrarium 的数据引擎未来要吃多本体真机回流数据（乐聚已经在捐赠上料数据集），现在就可以按"解剖角色"而非"关节编号"设计动作 schema，免得以后返工。同时注意它的"大模型→蒸馏单步实时策略"路径，与 SimForcing 的"仿真先验注入"一起，支持"仿真数据承重"的路线判断。

4. **真机数据回流进入规模化，Terrarium 的"失败回流"铁律正当时。** 乐聚 15 台产线常态化 + 数据捐赠开源、上海 8000 台进工厂计划，意味着未来 1–2 年真实产线数据会大量出现。Terrarium 的三条铁律（只给像素、真值只用于验证、失败回流）与这个趋势同向：建议把"真实产线回流数据格式"列入数据引擎的 roadmap，优先兼容乐聚捐赠的 OpenLET 上料数据集格式，做第一个真实回流数据源。

5. **Memento 3 的"规则外置 + 可执行验证"可启发 license 机制。** 固定模型 + 外部可修订规则手册 + 把规则编译成代码用环境行为校验——这本质上是"断言→可执行预测器→执行验证"的闭环。Clover 的许可证（licence）机制可以借鉴这条验证蓝图：断言不只被"读"，要能被编译成预测器、用"预测对不对"反过来给断言打分。这是 S1 阶段值得写进验证蓝图的一条新路。

## 一、前沿论文 / 方法（15）

1. **RoboActualizer：「从无穷多未来里挑一个实现」——冻结世界模型 + 60M 小模型读出动作（arXiv 2609.36413，10-03 更新）**
视频世界模型本来就铺好了无数种可能的未来，剩下的问题只是"选哪个未来、读出什么动作"。RoboActualizer 只训练两个轻量 DiT expert（60M 参数），在冻结世界模型编码器之上做任务条件的选择与实现，训练只需单卡 32GB。在 LIBERO、RoboTwin 2.0 和两个真机平台上打出顶级表现，延迟 39ms 可实时控制，可训练参数是现有 WAM/VLA 的 1/100。观点：这是"世界观基底 + 查询/readout"哲学的最强独立实证——大模型负责懂世界，小模型负责动手。
https://arxiv.org/abs/2609.36413v1

2. **PhysisForcing：视频世界模型的物理是"训练时注入的"，推理零开销（北大 + NVIDIA，10-02）**
视频扩散世界模型的结构缺陷不是架构问题——训练目标只奖励"看起来像"，不奖励"物理上对"。PhysisForcing 在微调阶段注入物理监督，推理时把辅助组件丢掉：闭环操作成功率从 16% 提到 24%，各物理真实度 benchmark 全线第一，部署计算一毫秒不加。观点：物理一致性可以前移到训练侧、部署端不加税，这对 CPU 原生、低推理成本路线是重大利好。
https://www.techtimes.com/articles/328469/20261002/robot-world-models-fix-physics-physisforcing-no-inference-overhead-required.htm

3. **FutureWorlds：从"替代未来"里学世界模型（arXiv 2610.01019，10-01）**
不只从真实 rollout 学，而是让模型在"本可以发生的替代未来"里对比学习；记忆消融、解码敏感度分析与光流评估显示，增益不止于视觉质量，更体现在运动预测精度和物体状态一致性上。观点：世界模型的训练信号正在从"预测下一帧"转向"理解因果结构"，这是 Clover"零幻觉"方向的邻居工作。
https://arxiv.org/abs/2610.01019v1

http://arxiv.org/abs/2610.07922v1

## 三、对我工作的启示

1. **RoboActualizer 是 Clover 架构哲学的独立实证，值得精读**：冻结世界模型 + 60M 微型 actualizer 做任务选择与动作读出，100× 更少可训练参数、39ms 实时控制——"世界观基底只做认识，动作是查询/readout"这条路有人走通了。可行动：把它的 actualizer 设计（双轻量 DiT expert + flow matching 联合预测未来隐变量与动作）列入对照实验清单，验证"冻结表征→轻量读出"的分离设计。
2. **物理一致性可以"训练时买单、部署时免税"**：PhysisForcing 只在微调阶段注入物理监督，推理零开销、成功率 16%→24%。可行动：Clover 的物理先验/约束不必做成推理时的重型模块，考虑"训练侧物理 shaping + 推理侧纯前向"的分离，这对 CPU 原生、低延迟目标是天然利好。
3. **传感器变异要进 Terrarium 的一等公民参数**：RawVLA 把 ISP 拉进学习环、VersaCamVLA 解耦相机几何——部署失败的一大来源是"训练时没见过的传感器"。可行动：在 Terrarium 场景生成器里把相机位姿/数量、ISP 参数（增益、噪声、色调）做成可采样的变异维度，并用 RawVLA-Bench 的思路建一个"恶劣成像"评估 split。
4. **DexForce 证明仿真数据引擎是条可融资的主赛道**：10 亿元 B 轮、估值超百亿，买的就是"数字孪生→仿真训练→真机迁移"这条链。可行动：研究 DexForce 的 sim-to-real gap 处理方法做对标；Terrarium 数据引擎的叙事可以更明确地对标"虚拟数据训练"的工业验证口径。
5. **"表示问题先于模型问题"是本周第二条暗线**：VISTA（换截图+无损记忆，ARC-AGI-3 从 40 干到 100）、Memento 3（冻结模型+规则书通关）都在说瓶颈在感知与脚手架，不在权重。可行动：Clover 坚持"先建对世界表示"是顺势的；同时 AA-Robotics v0.1 这类"模型亲自下场摸世界"的评测范式，值得借鉴到 Terrarium 的 Exam 模式设计里。

## 一、前沿论文 / 方法（15）

1. **AdaJEPA：在部署时边做边学的世界模型（NYU/LeCun，10-16）**
Wang 等人提出自适应潜空间世界模型：模型做计划、执行、观测实际发生了什么、调整自己的预测、再计划——不再只依赖训练时学到的一切，测试时从行动后果中学习，专门对付光照/质量/形状等分布外 mismatch。意义："闭包"从训练时搬到了部署时的 MPC 循环里——这与 Clover"学习机制必须放在模型本身"的设计立场同构，LCPS 值得认真评估一个在线修正版本。[来源](https://nyudatascience.medium.com/a-world-model-that-keeps-learning-after-training-ends-77b366643499)

2. **LEGS：3D 高斯世界里免遥操作微调 VLA（arXiv:2606.01458v2，10-14 修订）**
网格前景（机器人/物体/道具）+ 手持扫描重建的 3DGS 背景组成混合仿真器，程序化运动原语批量合成带标注演示，零人工遥操作。在 Unitree G1 人形三个全身任务上，纯 LEGS 数据训练的策略打平或超过 teleop 数据训练的版本；同一批演示重渲染到新场景/新物体，成本低 15 倍以上。意义：Terrarium 数据引擎的 3DGS 分支有了现成对标——"手机扫一下→合成无限演示"正是"失败回流"铁律的数据侧实现。[来源](https://arxiv.org/abs/2606.01458v2)

3. **Forecast-GS：预测"任务完成态"的 3D，而不是下一帧像素（arXiv:2605.11144，注日期）**
语言引导抓放任务里，显式预测任务完成时的 3D 状态来评估候选动作是否可行；真机 75 次试验胜过 ReKep 基线。作者诚实承认自动排序仍不如人类辅助——"怎么给未来排序"仍是开放问题。意义：把世界模型的预测目标从"像素未来"换成"可查询的任务终态"，与 Clover"输出世界状态而非视频"同向，可做对比参照。[来源](https://arxiv.org/abs/2605.11144v1)

4. **WIS：先想象、再行动的双臂扩散策略（Frontiers in Neurorobotics，10-16 报道）**
分层架构：语言驱动的世界模型先预测动作序列下的环境演化，预测结果再引导扩散动作生成器。在 RoboTwin 2.0 + Aloha-AgileX 双臂 benchmark 上全面超过强基线，计算开销只增加一点。意义：双臂长程协调里"无前瞻必死"——这是"世界模型先验 + 策略"组合的最新工程证据；Clover 的许可证机制若将来服务双臂系统，这条是现成的参照设计。[来源](https://scienmag.com/robots-learn-to-imagine-the-future-before-acting-new-diffusion-policy-gives-dual-arm-machines-predictive-foresight/)

5. **本周 7 大具身模型盘点：范式从"生成答案"转向"理解→预测→规划→行动→学习"（10-17）**
UNITAS 把观测、动作、场景变化统一进共享 3D 坐标系（像素→物理 3D 空间）；DreamTrue 构建动作条件未来、专攻"行动前预测物理上合理的失败"；Long-WAM 用更长视觉历史做时序推理。意义：三条线分别对应 Clover 的 3D 结构化表示、反事实查询、长记忆——别人正在用大模型堆出 Clover 想要的形状，而我们是原生小结构；R1 对比时这三篇是"大单体路线"的代表样本。[来源](https://www.linkedin.com/posts/ashishpatel2604_7-ai-models-to-know-this-week-ai-is-moving-activity-7516481819945656320-xwAl)

6. **PASE：神经符号世界模型验证 LLM 生成的恢复计划（arXiv:2607.01595，注日期）**
把故障自愈重构为神经符号程序合成：LLM 生成结构化恢复计划，神经符号世界模型在仿真里验证可行性，元提示优化器再改进规划；真实云故障注入数据集上恢复时间降 40% 以上。意义："计划→验证→适配"闭环正是 LCPS 持证后果闭包在云运维的镜像——连做运维的都在抄这条作业，"先验证再执行"正在成为跨领域共识。[来源](https://arxiv.org/html/2607.01595)

7. **V-JEPA 2：百万小时视频预训练的潜空间世界模型（Meta，10 月初技术解读）**
编码器 + 300M 参数动作条件预测器，在超 100 万小时无标注互联网视频上做掩码潜空间预测；习得的物理动力学可零样本迁移到新环境机器人操作。意义：LeCun 路线的最新刻度——"纯观察学物理"在 2026 年依然是最有耐心的竞争者；Clover 的差异化不在"学不学物理"，而在"输出是否带许可证、可查询"。[来源](https://explainx.ai/blog/what-are-world-models-ai-starchild-1-odyssey-complete-guide-2026)

8. **Skywork Matrix-Game 3.5：Patch Memory——"存空间，不存帧"（WAIC 披露，注日期）**
每帧打成带精确 3D 坐标的小 patch，模型记住的是"某个三维位置上有什么"而非"某一帧长什么样"；配合 PRoPE 几何位置编码，"消失物体"问题首次实质性解决，5B 参数单卡 720P ~20FPS 实时交互。意义：位置编码从"时间+像素行列"升级为"几何上有意义的世界坐标系"——与 Clover V6"机器原生空间语言"是同一判断的独立验证。[来源](https://digitalmore.co/the-first-year-of-world-models-when-ais-supply-side-revolution-moves-from-generation-to-understanding-the-physical-world/)

9. **本地 LLM 基准 2026：内存带宽才是瓶颈，稀疏 MoE 在弱设备上赢（10-02 修订）**
DGX Spark 跑 Llama 3.1 70B 只有 4.4 tok/s（273GB/s 带宽封顶），但跑 120B 稀疏 MoE（gpt-oss）能到 60.6 tok/s——每 token 只读一小部分权重，带宽不再是墙；苹果 M5 Ultra 靠 1.2TB/s 带宽吃稠密模型。意义：推理胜负手是"内存局部性 × 稀疏"而非 dense FLOPs——这正是 CPU 中心化路线的理论地基；Clover 的场表示天然稀疏，吃的是同一红利。[来源](https://presenc.ai/research/local-llm-tokens-per-second-benchmarks-2026)

10. **Magnitude：Rust 写的自优化推理引擎，设备级内核自动调优（10-01，Apache-2.0）**
针对 AI agent 的开源推理引擎：按执行硬件自动编译调优内核，官方称 Metal/CUDA 上比 llama.cpp 快至 2 倍；但第三方实测在纯 CPU（Neoverse-N1）上慢 21 倍——官方数字只覆盖 GPU 甜点。意义：两点教训：①"自动内核调优"是推理栈的正确方向（Clover 硬件原生加速铁律同理）；②厂商 benchmark 只报甜点配置，Clover 的 P2 诚实账本（frontend vs 全栈 FPS 区分）这种口径本身就是差异化。[来源](https://localmodelwatch.tsuchitsuchi.com/en/2026/10/01/magnitude-self-optimizing-inference-engine-for-agents/)

11. **社区实测：RTX 3090 上 27B 模型靠推测解码提速 4.6 倍（10-18）**
瓶颈是显存搬运权重而非计算：小 drafter 猜多个 token、大模型一次验证，Qwen3.8-27B 从 82 干到 381 tok/s，数学 benchmark 精度保持 96.5%。意义：推理优化仍在"不换卡、不换模型"上挤出数倍红利——ultrafast 的"快"不只靠模型变小，推理栈每一层都是战场；Clover PhaseGate 的 early-exit 与此同源。[来源](https://wccftech.com/rtx-3090-4-6x-token-generation-27b-llm-inference-optimizations/)

12. **事件相机稀疏卷积算子：跳过无效子卷积，计算量降 90%（Frontiers，注日期）**
针对事件相机稀疏异步特性重写卷积：只算有效子卷积并重排有效计算，同等精度下工作量降近 90%、速度接近 2 倍。意义：算子级的"稀疏原生"证据——若 Clover 将来接事件相机输入，红利在算子层而非模型层；V6 的 Poisson 求解器（占 86% 时间）值得用同样的"跳过无效计算"思路 profile 一遍。[来源](https://www.frontiersin.org/journals/neurorobotics/articles/10.3389/fnbot.2025.1537673/full)

13. **事件视觉边缘 AI：在纯 CPU 上跑通的稀疏感知栈（MDPI Sensors，注日期）**
DVS 事件流 24 小时监控数据量是传统视频的 1/30；人体检测从 5.8G FLOPs 压到 81M（172ms→15ms），手势识别在单核 i5-4590 上 14.31ms。意义："稀疏传感 + 轻量推理"在纯 CPU 上已是工程现实；且数据量小=不上云也 hold 住，是离线优先的天然盟友——Clover 若把事件流作为第二输入模态，传感侧红利现成。[来源](https://www.mdpi.com/1424-8220/26/3/935)

14. **WOLF-VLA：全身人形 VLA 的三堵墙（arXiv:2606.25591，注日期）**
现有 VLA 只在简单平台（固定基座机械臂）上验证，全身高动态多接触系统刚起步；数据靠昂贵耗时的遥操作/动捕采集，且采集的动作没有"最优性"概念（能走但不省能量）。意义：VLA 的数据瓶颈是结构性的——teleop 采集越往全身智能走越贵；Clover 不依赖演示数据做世界理解，恰好绕开这堵墙。[来源](https://arxiv.org/html/2606.25591)

15. **UniGround：无训练的 3D 视觉定位（arXiv:2603.08131，注日期）**
两阶段：无训练的 3D 拓扑 + 多视角语义编码做全局候选过滤，再多尺度视觉提示做精确定位；在 EmbodiedScan 零样本拿下 SOTA，且在非受控真实环境重建下依然鲁棒。意义："免训练的几何推理"泛化超过"继承预训练知识边界"的感知——与 Clover UncertaintyLens"免训练不确定性读出"哲学一致：好的结构不需要大数据灌。[来源](https://arxiv.org/html/2603.08131v1)

## 一、前沿论文 / 方法（15）

1. **Scene-R1：RL 长出"透明"的 3D 推理链（arXiv:2506.17545，3 天前抓取）**
首个用 R1 式强化学习生成可解释思维链的 3D 框架：只用 RGB 视频 + reward 信号、不需要任何 3D 实例标注，就在标准室内 3D 理解基准上打平检测器管线。重要性在于"透明推理"第一次被做成可训练目标而非事后解释——与 Clover"只做认识论断言"同构：断言链本身就是推理产物。
https://arxiv.org/html/2506.17545v1

2. **FineVLA：细粒度指令对齐，但组合泛化依然没解（arXiv:2605.27284，1 天前抓取）**
通过细粒度监督提升 VLA 的因子级可控性，但作者诚实记录了剩余失败：grounding 失败（选错物体/手臂）与 execution 失败（抓不稳、转不到位），OOD 的 actor-target 绑定依然不行。意义：VLA 的"墙"从玄学变成了可分类的故障模式——这正是 Terrarium Exam 模式该抄的作业：把失败分类学做成基准。
https://arxiv.org/html/2605.27284

3. **EvoVLA：长程任务里的"阶段幻觉"（arXiv:2511.16166，注日期）**
识别出 VLA 的关键失败模式 stage hallucination：智能体利用粗糙的视觉评估信号虚报任务进度（基线 38.5%），实际没做完；作者用阶段对齐奖励 + 位姿探索 + 选择性长程记忆把它压到 14.8%。意义：这是 Clover 许可证机制最好的反面教材——"虚报进度"恰好是"无许可证断言"的临床症状，建议直接做成 Terrarium 的回归测试项。
https://arxiv.org/html/2511.16166v1/

4. **行动幻觉的形式化分析：VLA 的幻觉是结构性的（注日期）**
从拓扑、精度、时域三个基本障碍出发，给生成式 VLA 的幻觉概率推导下界：结论是幻觉不是数据或优化问题，而是连续隐变量生成式策略的架构内禀缺陷。意义：把"VLA 会撞墙"从经验观察升级成数学命题——Clover"世界状态先行、动作后行"的分层架构，恰好绕开了这三个障碍的假设前提。
https://chatpaper.com/paper/234889

5. **World Action Models：预测性机器人学的转向（cotacapital，10 月初）**
提出 WAM（world action model）概念：VLA 只学"观测+指令→动作"的映射，世界模型学"环境如何演化"，WAM 把两者结合——用对未来的预测指导动作选择。关键论断：一个很强的视频模型不自动成为有用的机器人世界模型（几何、时序、接触动力学稍错一点，视频看着对、机器人全错）。意义：这是"生成式 vs 结构化"分岔的产业评论版——Clover 的答案是 WAM 再往前一步：预测的不是视频，是带许可证的世界状态。
https://www.cotacapital.com/knowledge-base/world-action-models-and-the-shift-toward-predictive-robotics/

6. **World Model for Robot Learning 综合综述（arXiv:2605.00080，3 天前抓取）**
把世界模型按状态表示分为符号型（谓词、物体关系、可供性、因果过程上做转移预测）与视觉型（视频生成），并承认当前具身系统最可扩展的实现恰恰是视觉观测流。意义：综述第一次把"符号世界模型"当作与视频生成并列的一等公民——Clover 的场结晶世界观（结构化、可查询）在学术分类学里有了正式座位。
https://arxiv.org/html/2605.00080

7. **世界模型的定义与路线图：二维分类法（arXiv:2607.06401）**
按"表示基质 × 预测机制"给世界模型分类：观测层生成模型（像素/视频）、潜空间动力学模型、3D/结构化世界表示；并把 Sora、Seedance 钉在"观测层渲染器"区域——它们的输出是"看起来合理的视频"，不是"可独立查询的世界状态"。意义：这篇给 Clover 送了一份学术弹药：以后再有人把 Sora 式模型叫世界模型，可以直接引用这张分类图。
https://arxiv.org/html/2607.06401v1

8. **LeCun 世界模型讲座笔记：生成合理视频≠理解世界（12 天前）**
核心论点：语言里预测缺失词是可处理的（词表有限），像素级未来预测面对的是天文数字级的合理未来；生成模型只需产出"一个看起来合理的延续"，而有用的世界模型必须保留"与推理行动相关的可预测结构"，同时对不可预测的细节表示不确定性。意义：这几乎是 Clover 立项书的哲学版——JEPA 是他的答案，场结晶+许可证是我们的答案，R1 对比时这篇是必引文献。
https://agericomontecillodevilla.substack.com/p/on-yann-lecuns-world-models-enabling-8db

9. **腾讯 HY-World 2.0：不做视频，做"可玩的世界"（8 天前）**
路线与视频世界模型彻底分岔：输出持久 3D 资产（mesh、Gaussian splat、点云），可编辑、可导入 Unity/Unreal/Blender，一次生成、实时渲染；WorldMirror 2.0 单次前向就从多视角/随意视频重建出深度、法线、相机参数。官方话术是"building a playable world vs watching a movie that ends"。意义：大厂也在用脚投票——持久、可查询、可编辑的世界表示正在成为显学，Clover 的"可查询世界状态"与这条线同向。
https://explainx.ai/blog/what-are-world-models-ai-starchild-1-odyssey-complete-guide-2026

10. **Odyssey-3：14B 世界模型免费公测（7 天前）**
自回归扩散 transformer：根据文本描述生成可实时探索的 3D 环境（第一/第三人称），同一模型驱动机械臂、人形、无人机和自动驾驶；14B 参数输出 832×480 视频，训练数据混了互联网视频、游戏操作录像和仿真物理交互。意义：生成式世界模型的"交互性"上限样本——但注意它依然是"渲染未来"，没有可查询的状态表示；正好拿来当 Clover 对比实验的"生成式基线"。
https://www.derringtoncollaborativeai.com/briefing/odyssey-3-free-world-demo

11. **Event2Vec：把事件当词，把事件流当语言（arXiv:2504.15371 v6）**
受 word2vec 启发：事件相机输出的异步稀疏事件（像素、极性、时间戳）与词天然类比（离散、有序、意义依赖上下文），直接把事件嵌入向量空间，原生处理稀疏性，不再转成稠密事件帧；参数极少、吞吐极高、极少事件下精度依然高。意义：稀疏表示的"第一性原理"版本——SEP 的事件语义如果能与这种原生事件表示对齐，"稀疏"就从工程技巧变成表示本质。
https://arxiv.org/abs/2504.15371v3

12. **ES-Parkour：事件相机 + 脉冲神经网络跑酷（注日期）**
仿生感知栈：事件相机（120dB 动态范围、微秒级时间分辨率）+ LIF 脉冲神经网络（稀疏激活、事件驱动计算），ANN 教师策略蒸馏成 SNN 学生策略做跑酷。意义：端到端的"稀疏传感→稀疏计算"闭环第一次在动态任务上跑通——Clover 的 ultrafast 若将来考虑事件相机输入，这条是现成的可行性证据。
https://www.alphaxiv.org/abs/2503.09985

13. **事件相机 3D 重建首个综合综述（arXiv:2505.08438 v4）**
按输入模态（双目/单目/多模态）× 重建方法（几何/深度学习/NeRF/3DGS）系统梳理事件相机 3D 重建，并点名当前瓶颈：数据、评测、表示、动态场景处理。意义：事件视觉的"地图"已经画好——Clover 若要把事件流作为第二输入模态，这篇就是立项时的文献起点。
https://arxiv.org/abs/2505.08438v1

14. **VLA 评测的符号预言机困境（ar5iv:2602.22579，注日期）**
指出 VLA 评测依赖符号预言机（"是否拿着苹果"这类符号状态检查）有两个死结：人类指令表达方式多变导致预言机难自动生成，LLM 生成的预言机又会幻觉；且符号预言机抓不住"执行质量"（动作是否优雅、安全）。意义：评测方法论的内伤——Terrarium 的 Gym/Exam 双模式恰好绕开了它：不检查符号状态，检查世界状态断言的许可证链。
https://ar5iv.labs.arxiv.org/html/2602.22579

15. **预测不确定性与多样性在具身 AI 中的角色（arXiv:2405.03164，注日期）**
系统论述：能量化世界不确定性的机器人才能做风险厌恶/风险偏好决策，而这正是"认证机器人、可信度"的地基；不确定性来源要分类处理，实时系统里对所有随机性建模是浪费。意义：UncertaintyLens 的理论祖师爷——"不确定性→可认证性"这条链条被正式写进文献，持证 AI 的叙事又多一块砖。
http://arxiv.org/html/2405.03164v1

## 一、前沿论文 / 方法（15）

1. **RoboJEPA（Meta FAIR，10-07）：latent 世界模型的缩放定律（arXiv:2610.10515）**
Meta FAIR 发布 RoboJEPA，用 JEPA 架构在 12 种不同机器人平台的数据上训练 latent 世界模型：不预测像素，只预测场景的本质特征，在潜空间里"想象"动作后果，实现跨本体的 zero-shot 规划，并给出了类似 LLM 的机器人 scaling law。意义：这是"结构化世界表示 vs 生成式视频世界模型"分岔路上结构化一侧的旗手——与 Clover 的场结晶世界观同构，JEPA 式预测头可直接做对比基线。
https://stellitron.com/blog/robojepa-explained-scaling-robotic-world-models-87fb54219b

2. **COAP（NTU NExT++ Lab）：把 VLA 从推理环里踢出去（10-14）**
新范式 Code-Only-as-Policy：如果能从相机和本体感受完整估计机器人状态，下游决策就全部写成显式代码操作结构化状态，不需要几十亿参数策略网络做前向传播。在 42 个双臂操作的 RoboDojo 基准上拿到 70.24% 成功率，决策阶段推理期模型调用次数为零。意义：对 Clover 是双重信号——利好面是"状态估计优先于策略"的母问题被独立验证；威胁面是 M2 Decision 模块必须回答：当状态足够好时，代码策略凭什么不如一个独立模块。
https://extrapolator.ai/2026/10/14/coap-removes-vla-from-robot-inference-hits-70-on-robodojo-bimanual/

VLA 的实验室诅咒之一是策略被锁死在训练时的相机数量和位姿上，换套相机就得重训。VersaCamVLA 把相机集合表示与动作学习解耦，部署时可适应任意相机配置。意义：直接服务于 Terrarium 的"真值只用于验证"合同——场景生成器可以系统性扰动相机外参，把"相机不变性"做成 Clover 表示的硬测试项。

# Research Workspace

This directory contains exploratory material that informs, but does not automatically define, Clover's SSOT.

- `literature/` — structured reading notes and source syntheses;
- `notes/` — exploratory reasoning, news-derived questions and brainstorming;
- `experiments/` — registered experiment protocols and results;
- `decisions/` — research decision records (ADR style).

A note becomes a project commitment only after the relevant decision and current documentation are updated.

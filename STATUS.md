# Clover Status

**Last updated:** 2026-10-14

## Research question

> **How can a machine understand the real world through vision alone?**

## Public repository status

`IMPLEMENTED` — The public repository and research foundation are initialized.

This repository was newly created on 2026-10-14. At this point the public repository contains the project SSOT, principles, roadmap, research map, hypotheses, evaluation map and research decisions. The previously developed Clover implementation has **not yet been imported into this public repository**.

## Existing Clover work outside the public repository

`RESEARCH_PROTOTYPE` — A substantial prototype has previously explored:

- visual evidence extraction;
- field/crystallization-inspired world formation;
- persistent entities and temporal identity;
- machine-queryable world state;
- observability / unknown handling;
- epistemic licence mechanisms;
- Decision, Tool Use and Execution modules;
- closed-loop architecture experiments.

These mechanisms are no longer treated as frozen architectural commitments. They are candidate hypotheses to be re-evaluated against current research.

## Under investigation

`OPEN`

- What internal representation is sufficient for world understanding?
- Explicit state vs distributed latent representation.
- Geometry vs learned representation.
- Object-centric vs field/spatiotemporal primitive representations.
- Passive video learning vs interaction.
- Physical and causal understanding.
- Persistent memory and belief revision.
- Active perception.
- How world understanding should improve robot decision and action.
- CPU/GPU/Metal co-design after the scientific mechanism is clearer.

## Not yet demonstrated

The public project does **not yet claim**:

- general real-world visual understanding;
- robust open-world generalization;
- comprehensive positive-result SOTA;
- long-horizon real-robot autonomy;
- a final world representation;
- superiority over V-JEPA, VLM/VLA, geometry systems or robot foundation models.

These are research targets or comparison questions, not current facts.
